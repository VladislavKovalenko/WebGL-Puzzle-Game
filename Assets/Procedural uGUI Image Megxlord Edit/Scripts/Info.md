⚠️ Важные примечания
Градиент / Обводка / Маска / Паттерн — требуют доработки шейдера UI/Procedural UI Image. 
В C# добавлены только свойства и передача значений в материал. Без шейдерной поддержки визуально работать не будет.

Star / Heart / Polygon / Hexagon / Speech Bubble — текущая архитектура основана на 4 угловых радиусах прямоугольника. Для точных фигур (звезда, сердце) нужна кастомная генерация меша. Данные модификаторы возвращают максимальное скругление как приближение.

9-Slice — добавлено поле use9Slice, но полная реализация требует переписывания OnPopulateMesh.

Undo/Redo — добавлен Undo.RecordObject / Undo.RecordObjects в Editor.

Capsule / Squircle / Arrow / Diamond — полностью работают с текущей системой.
